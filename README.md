# ScholarEngine

**GODSPEED** 🚀

A Next.js-powered academic search companion.

## Features

- ⚡ Built with Next.js 16 (App Router)
- 🎨 Styled with Tailwind CSS
- 📊 Integrated with Vercel Web Analytics
- 🔤 Uses Geist font family
- ⚙️ TypeScript support

## Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `src/app/page.tsx`. The page auto-updates as you edit the file.

## Analytics

This project includes Vercel Web Analytics. Once deployed to Vercel, analytics will be automatically enabled. You can view analytics data in your Vercel dashboard under the Analytics tab.

## Build

To create a production build:

```bash
npm run build
```

To start the production server:

```bash
npm start
```

## Code Quality

Run the linter:

```bash
npm run lint
```
