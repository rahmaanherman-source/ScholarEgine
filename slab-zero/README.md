# APEX Memory Slab / Slab-Zero

**Start here.** An AI or human entering this repository should read `manifest.json`, `roadmap.json`, `policy.json`, then `standards/verification-law.md`.

The manifest is the machine-readable state ledger. It contains only proven state. Follow each `evidence_locator` to inspect the underlying proof. `VERIFIED` is historical provenance; `CURRENT` is temporal validity. `STALE` preserves the historical proof while requiring re-verification.

Completion is weighted and derived from roadmap items. A section can be verified and used independently; that does not imply the entire project is complete.

Never manually edit a status to VERIFIED or a completion percentage. The authorized Gatekeeper state transition must establish those values from evidence and provenance.
